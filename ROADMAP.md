# Roadmap

This roadmap describes ideas, not delivery commitments. Priorities may change based on user feedback and contributor availability.

## v3.1 — usability and Raspberry Pi

- [ ] Optimize memory use and image processing for Raspberry Pi 3 (the stated minimum hardware target).
- [ ] Document trusted-LAN hosting on Raspberry Pi and an optional `systemd` service for automatic startup; include safe firewall and service-user guidance.
- [ ] Show record photos immediately in every gallery view by using generated thumbnails consistently (including list and tile views).

## Later ideas

- [ ] **v2 data migration:** provide a documented, tested migration path from the previous application's data format, with backup-first safeguards.
- [ ] **v4 import:** explore more flexible import workflows (including metadata-aware grouping, broader file handling, and a guided review step).
- [ ] Add more automated cross-platform and real-device performance coverage.

To suggest or discuss roadmap changes, open a GitHub feature request or discussion.
